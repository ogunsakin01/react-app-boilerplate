# Guides

The boilerplate is deliberately opinionated and deliberately narrow. These guides show how to add the things we intentionally left out. without breaking anything else.

| Guide                          | What it adds                                |
| ------------------------------ | ------------------------------------------- |
| [Auth](./auth.md)              | User sessions via an external auth provider |
| [State management](./state.md) | Global client state beyond React Query      |
| [i18n](./i18n.md)              | Multi-language support                      |
| [Docker](./docker.md)          | Containerized dev + build                   |
